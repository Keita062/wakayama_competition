# レビュー依頼についての検討「5. 目的を叶えるための方法」の所の検討

* ①どの分野に手を打つべきか
* ②その分野は、周知・運用で実感を上げられるのか、環境そのものを変える必要があるのか
* ③環境を変えるなら、どの指標をどこまで動かすのか
* ④その打ち手で幸福度がどれだけ動くのか

という形になってる。

ただ、分析の流れを具体的に考えていく中で、分析と上手くマッチしていないように感じたのと、②〜④が少し飛んでいるように感じた。

特に②の「ソフト施策で実感を上げられるのか／ハード施策が必要なのか」は、必ずしも2値で分けられるとは限らないし、実際にはソフト・ハードの両方を提案する可能性もあるので、ここを最終的に言えることとして置く必要はないかなと思った。

また、③も「環境を変えるなら」という②を前提にした内容になっているので、②を変えるのであれば、③も合わせて見直した方がいいかなと思った。

そこで、分析から政策提言までを終えたとき、最終的に以下の4つが言えたらいいんじゃないかな？？

1. 「どの分野に手を打つべきか」
2. 「その分野で具体的に何を改善すべきか」
3. 「その改善について、どこまでを目標とし、改善した場合に幸福度がどの程度変化すると見込まれるか」
4. 「そのために、具体的にどのような行政施策を実施すべきか」

こっちの方が僕たちの今の分析の流れに近いと思うし、最終的に「何を、どこまで、どんな施策で改善し、その結果として幸福度がどれくらい変化すると見込まれるのか」までつなげられると思ってはいる。

---

### 最終的に言えるようにすることと効果

| # | 最終的に言えるようにすること | それが言えると何ができるか |
| :--- | :--- | :--- |
| **1** | どの分野に手を打つべきか（優先順位と、その根拠） | 予算を振り向ける先が決まる |
| **2** | その分野で具体的に何を改善すべきか | 改善すべき具体的な対象が決まる |
| **3** | その改善について、どこまでを目標とし、改善した場合に幸福度がどの程度変化すると見込まれるか | 目標値と期待される効果を定量的に示せる |
| **4** | そのために、具体的にどのような行政施策を実施すべきか | 具体的な施策に落とし込み、費用対効果を踏まえた政策判断につなげられる |
