# 目的
和歌山県の主観的ウェルビーイング（住民が実際に感じている幸福度・生活満足度）を向上させるために、どんな手を打つべきかを、地域幸福度（Well-Being）指標のデータから導き出す。

# 前提
言葉の共通認識が必要
* **目的変数**：幸福度
* **カテゴリ内の主観の値**：主観スコア
* **カテゴリ内の客観の値**：客観スコア
* **客観スコアを構成している要素**：客観的構成値
* **客観構成スコア以外の変数**：潜在変数（※厳密には客観構成スコアに含まれない追加要因）

# 当初の進め方（言葉を共通認識に変更）
1. 幸福度に対して、主観スコアのカテゴリには何が一番寄与しているのか。
2. 客観スコアに対して、主観スコアが下振れているカテゴリは何か。
3. そのカテゴリの主観スコアをあげることはできるのかできないのか。
4. できないなら客観スコアのなにをあげたほうがいいのか。潜在的に考えられないもの（潜在変数）も考慮した上で。
5. そのソリューションを考える。

# この進め方の課題と改善点

## 1. 全体
* **課題**：当初のSTEP 1で「幸福度に対してどのカテゴリーが関連するか」を分析しているが、その結果がその後のカテゴリー選定や施策検討に十分活用されていない。
* **変更理由**：寄与率が大きいカテゴリは、主観スコアとの関連が強く、政策的に検討する意義が大きい。そのため、STEP 1の分析結果を後続の分析に活用したほうが、分析全体の一貫性が高くなる。
* **改善点**：幸福度との関連の大きさを、重点カテゴリーの選定要因として活用する。

## 2. 「一番寄与するカテゴリー」を1つに限定
* **課題**：「一番寄与しているカテゴリー」を1つだけ特定する設計になっている。
* **変更理由**：関連性が高いカテゴリーであっても、具体的な施策につなげにくい場合がある。1つだけに限定すると、政策提案につながる可能性のある他のカテゴリーを除外してしまう可能性がある。
* **改善点**：幸福度との関連が大きいカテゴリーを複数特定し、重点カテゴリーの候補とする。

## 3. 「下振れ」を重点カテゴリーの選定基準とする
* **課題**：「客観スコアに対して主観スコアが下振れているカテゴリー」を重点カテゴリーとして選定する。
* **変更理由**：客観スコアと主観スコアは指標の性質や尺度が異なるため、両者の差を単純に計算して「下振れ」と評価することは適切ではない。また、客観スコアに対して主観スコアが低いことが、必ずしも主観スコアの改善余地が大きいことを意味するわけではない。
* **改善点**：「下振れ」を選定基準とするのではなく、幸福度との関連性と和歌山市の主観スコアを重点カテゴリーの選定要因とする。主観スコアを目的変数としているため、和歌山市における主観スコアの水準を重点カテゴリーの選定に用いる。

## 4. 「主観スコアを上げることができるか」の前に、主観スコアを客観的構成値で説明できるかを確認
* **課題**
  * 「そのカテゴリーの主観スコアを上げることができるか」という分析に直接進む設計になっている。
* **変更理由**
  * 主観スコアの向上を検討する前に、まず主観スコアが既存の客観的構成値によってどの程度説明できるのかを確認する必要があるため。
  * 客観的構成値で十分に説明できる場合は、それらを改善候補として扱うことができる。一方、十分に説明できない場合は、既存の客観的構成値だけでは捉えられていない要因が存在する可能性があるため、追加要因（潜在変数）を探索する必要がある。
* **改善点**
  * 「主観スコアを上げることができるか」を検討する前に、「主観スコアを客観的構成値でどの程度説明できるか」を確認するステップを追加する。
    * **十分に説明できる場合**：既存の客観的構成値を改善候補として、主観スコアの向上が見込めるかを検討する。
    * **十分に説明できない場合**：既存の客観的構成値に加えて、主観スコアと関連する追加要因（潜在変数）を探索する。



# 改善点を踏まえた提案




| STEP | 分析内容 | 主な目的 |
| :--- | :--- | :--- |
| **STEP 1** | 24カテゴリーの**主観スコア**と**幸福度**の関連性を確認 | **幸福度**と関連しているカテゴリーを複数特定する |
| **STEP 2** | 重点カテゴリーを選定 | **幸福度**との関連性と和歌山市の**主観スコア**を踏まえて、優先的に分析するカテゴリーを決める |
| **STEP 3** | 重点カテゴリーの**主観スコア**を、**客観的構成値**で説明できるかを確認 | **客観的構成値**による**主観スコア**の説明力を確認する |
| **STEP 4A** | **【客観的構成値で十分に説明できる場合】**<br>追加要因の探索は行わず、STEP 5へ | 既存の**客観的構成値**を改善候補として扱う |
| **STEP 4B** | **【客観的構成値だけでは十分に説明できない場合】**<br>追加要因を探索 | **客観的構成値**だけでは説明できない**主観スコア**の変動に関連する要因を探索し、改善候補に加える |
| **STEP 5** | STEP 4A・4Bで得られた改善候補のうち、主観スコアの向上が見込まれる改善候補を特定・絞り込み| STEP 4A・4Bで得られた改善候補について、数値を伸ばした場合に主観スコアの向上が見込まれるものを、他自治体との比較等から特定・絞り込む |
| **STEP 6** | 改善候補の改善余地を評価 | STEP 5で絞り込んだ改善候補について、和歌山市で数値を伸ばす余地があるかを確認する |
| **STEP 7** | 改善候補への目標値設定と**主観スコア**の向上シミュレーション | 改善余地のある改善候補に目標値を設定し、**主観スコア**がどの程度変化するかを試算する |
| **STEP 8** | **行政施策**の介入可能性・時間軸を整理 | 各改善候補を**行政施策**によって改善できるか、また短期・中期・長期のどの時間軸で実現可能かを整理する |
| **STEP 9** | 政策提案とロードマップ作成 | 分析結果を具体的な**行政施策**と実行計画に落とし込む |

※ **用語の定義**
* **改善候補**：STEP 4Aでは「客観的構成値」、STEP 4Bでは「客観的構成値」に加えて探索した「追加要因」
