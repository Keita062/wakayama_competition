# 目的
和歌山県の主観的ウェルビーイング（住民が実際に感じている幸福度・生活満足度）を向上させるために、どんな手を打つべきかを、地域幸福度（Well-Being）指標のデータから導き出す。

# 前提
言葉の共通認識が必要
* **目的変数**：幸福度
* **カテゴリ内の主観の値**：主観スコア
* **カテゴリ内の客観の値**：客観スコア
* **客観スコアを構成している要素**：客観的構成値
* **客観構成スコア以外の変数**：潜在変数（※厳密には客観構成スコアに含まれない追加要因）

# 当初の進め方（言葉を共通認識に変更）
1. 幸福度に対して、主観スコアのカテゴリには何が一番寄与しているのか。
2. 客観スコアに対して、主観スコアが下振れているカテゴリは何か。
3. そのカテゴリの主観スコアをあげることはできるのかできないのか。
4. できないなら客観スコアのなにをあげたほうがいいのか。潜在的に考えられないもの（潜在変数）も考慮した上で。
5. そのソリューションを考える。

# この進め方の課題と改善点

## 1. 全体
* **課題**：当初のSTEP 1で「幸福度に対してどのカテゴリーが関連するか」を分析しているが、その結果がその後のカテゴリー選定や施策検討に十分活用されていない。
* **変更理由**：寄与率が大きいカテゴリは、主観スコアとの関連が強く、政策的に検討する意義が大きい。そのため、STEP 1の分析結果を後続の分析に活用したほうが、分析全体の一貫性が高くなる。
* **改善点**：幸福度との関連の大きさを、重点カテゴリーの選定要因として活用する。

## 2. 「一番寄与するカテゴリー」を1つに限定
* **課題**：「一番寄与しているカテゴリー」を1つだけ特定する設計になっている。
* **変更理由**：関連性が高いカテゴリーであっても、具体的な施策につなげにくい場合がある。1つだけに限定すると、政策提案につながる可能性のある他のカテゴリーを除外してしまう可能性がある。
* **改善点**：幸福度との関連が大きいカテゴリーを複数特定し、重点カテゴリーの候補とする。

## 3. 「下振れ」を重点カテゴリーの選定基準とする
* **課題**：「客観スコアに対して主観スコアが下振れているカテゴリー」を重点カテゴリーとして選定する。
* **変更理由**：客観スコアと主観スコアは指標の性質や尺度が異なるため、両者の差を単純に計算して「下振れ」と評価することは適切ではない。また、客観スコアに対して主観スコアが低いことが、必ずしも主観スコアの改善余地が大きいことを意味するわけではない。
* **改善点**：「下振れ」を選定基準とするのではなく、幸福度との関連性と和歌山市の主観スコアを重点カテゴリーの選定要因とする。主観スコアを目的変数としているため、和歌山市における主観スコアの水準を重点カテゴリーの選定に用いる。

## 4. 「主観スコアを上げることができるか」という考え方
* **課題**：「そのカテゴリーの主観スコアを上げることができるか」という表現になっている。
* **変更理由**：ここでは、主観スコアを客観スコアで「あげる」ではなく「説明できるか」とした方がいい。「主観スコアを上げることができるか」では、客観指標を改善することで主観スコアが上昇するという因果関係を検証するように受け取られるが、実際、因果関係があるとは限らない。
* **改善点**：「主観スコアを客観的構成値でどの程度説明できるか」を分析する。その結果から、主観スコアと関連する具体的な客観的構成値を改善候補として特定する。

## 5. 「客観スコアの何を上げるべきか」という考え方
* **課題**：「客観スコアの何を上げたほうがいいのか」を検討する設計になっている。
* **変更理由**：客観スコアは複数の客観的構成値から構成されているため、客観スコアだけでは具体的な改善対象を特定できない。また、客観的構成値だけでは主観スコアを十分に説明できない場合、既存の指標だけでは捉えられない要因が存在する可能性がある。
* **改善点**：客観的構成値まで分解して分析し、主観スコアと関連する改善候補を特定する。客観的構成値で十分に説明できない場合は、追加要因（潜在変数）を探索する。

# 改善点を踏まえた提案

| STEP | 分析内容 | 主な目的 |
| :--- | :--- | :--- |
| **STEP 1** | 24カテゴリーの主観スコアと幸福度の関連性を確認 | 幸福度と主観スコアの関連が強いカテゴリーを複数特定する |
| **STEP 2** | 重点カテゴリーを選定 | 幸福度と主観スコアの関連性と和歌山市の主観スコアを踏まえて、優先的に分析するカテゴリーを決める |
| **STEP 3** | 重点カテゴリーの主観スコアを、客観的構成値で説明できるかを確認 | 客観的構成値による主観スコアの説明力を確認する |
| **STEP 4A** | 【説明力が十分な場合】 追加要因の探索は行わず、STEP 5へ | 客観的構成値を改善候補として扱う |
| **STEP 4B** | 【説明力が十分でない場合】追加要因の探索 | 客観的構成値だけでは捉えられない主観スコアとの関連要因を探索する |
| **STEP 5** | 改善候補の重要度を評価 | STEP 4A・4Bで得られた改善候補について、主観スコアとの関連の大きさ等から優先順位を付ける |
| **STEP 6** | 介入可能性・時間軸を整理 | 各改善候補を、自治体による介入可能性や短期・中期・長期の時間軸から整理する |
| **STEP 7** | 政策提案 | 分析結果を具体的な施策に落とし込む |
| **STEP 8** | 政策ロードマップの作成 | 短期・中期・長期の施策として整理する |
