# データ構成

本研究では、デジタル庁「地域幸福度（Well-Being）指標」のデータを使用する。
地域・年度・属性別に以下のデータを取得できる。

## 1. 幸福度・生活満足度

**ファイル**
*_幸福度・生活満足度.csv

**内容**
幸福度・生活満足度などの回答分布を格納したデータ。

| 項目 | 内容 |
| --- | --- |
| 年度 | 調査年度 |
| 調査種別 | 全国調査 |
| 地域 | 都道府県・市区町村 |
| データ種別 | 幸福度・生活満足度 |
| 設問 | 幸福度、生活満足度など |
| 回答 | 回答値（1～10） |
| 回答割合 | 各回答値の割合 |

**設問**
* 幸福度
* 生活満足度
* 5年後の幸福度
* 町内の幸福度
* 周りも楽しい

## 2. カテゴリー別

**ファイル**
*_カテゴリー別.csv

**内容**
地域幸福度（Well-Being）指標の24カテゴリについて、主観評価と客観評価を整理したデータ。

| 項目 | 内容 |
| --- | --- |
| 年度 | 調査年度 |
| 調査種別 | 全国調査 |
| 地域 | 都道府県・市区町村 |
| データ種別 | カテゴリー別 |
| 因子群 | 生活環境、地域の人間関係、自分らしい生き方 |
| カテゴリ・評価指標 | 24カテゴリ |
| 主観データ実数 | 住民による主観評価 |
| 主観データ偏差値 | 主観評価の偏差値 |
| 客観データ偏差値 | 客観評価の偏差値 |

**24カテゴリ**
* 生活環境
  * 医療・福祉
  * 買物・飲食
  * 住宅環境
  * 移動・交通
  * 遊び・娯楽
  * 子育て
  * 初等・中等教育
  * 地域行政
  * デジタル生活
  * 公共空間
  * 都市景観
  * 自然景観
  * 自然の恵み
  * 環境共生
  * 自然災害
  * 事故・犯罪
* 地域の人間関係
  * 地域とのつながり
  * 多様性と寛容性
* 自分らしい生き方
  * 自己効力感
  * 健康状態
  * 文化・芸術
  * 教育機会の豊かさ
  * 雇用・所得
  * 事業創造

## 3. 主観

**ファイル**
*_主観.csv

**内容**
住民による主観評価を格納したデータ。
このファイルには、因子群に関連する個別の主観評価指標と、それらをまとめた24カテゴリの主観スコアが含まれている。

| 項目 | 内容 |
| --- | --- |
| 年度 | 調査年度 |
| 調査種別 | 全国調査 |
| 地域 | 都道府県・市区町村 |
| データ種別 | 主観データ |
| 因子群 | 生活環境、地域の人間関係、自分らしい生き方 |
| カテゴリ・評価指標 | 評価指標と24カテゴリ |
| 実数 | 主観評価の実数値 |
| 偏差値 | 主観評価の偏差値 |

**評価指標**

因子群に関連する、より詳細な住民の評価を格納している。

例えば「生活環境」では、

* 医療機関が充実
* 介護福祉サービス良
* 買い物に不便がない
* 飲食を楽しめる
* 公共交通の移動良
* 娯楽施設がある

などの個別評価指標が含まれる。
