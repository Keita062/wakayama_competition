# 「和歌山 地域類型×個別KPI分析」再現用データ整備

作成日：2026-10-06

## 1. このドキュメントの目的

[wakayama_region_type_kpi_analysis.pdf](../00_context/wakayama_region_type_kpi_analysis.pdf)（以下「PDF」）の分析を再現するために、使うデータとスクリプトを整備しました。このドキュメントには次のことを書いています。

- PDFの各ステップで、どのデータのどの列を使うか
- データをどのスクリプトで取得・整形したか
- PDFの値とどこまで一致したか（照合結果）と、再現できていない点

> 整備したのは「データ」までです。PDFの分析そのもの（類型分け、寄与度、固定効果モデルなど）のスクリプトはまだありません（[8章](#8-未対応次にやること)）。

## 2. 全体像

```
デジタル庁ダッシュボード ─────────────────────────┐
  （主観・幸福度・客観24分野スコア）               │
                                                     ├─→ PDFの分析（未作成）
各出典（国勢調査・都市モニタリングシートなど12か所）│
  └→ 01_download（取得）→ 01_raw（原本）            │
       └→ 02_build（整形）→ 02_processed ──────────┘
            （市区町村 × 類型6変数・個別KPI28本）
```

PDFの分析に使うデータは、次の2系統です。

| 系統 | 中身 | ファイル | 作り方 |
|---|---|---|---|
| A. ウェルビーイング指標 | 主観24分野・幸福度など（年代×性別まで）、客観24分野スコア。2022〜2026年度版 | [地域幸福度_市区町村別データ_2022-2026.xlsx](../00_context/地域幸福度_市区町村別データ_2022-2026.xlsx) | 受領データ（デジタル庁ダッシュボードから2026-09-21に収集）。このフォルダでは作っていない |
| B. 類型6変数・個別KPI | 市区町村ごとの類型6変数と個別KPI 28本の元の値 | [01_市区町村別_個別KPI.csv](../04_data/02_processed/01_市区町村別_個別KPI.csv) | 今回整備。各出典から取得して整形した（[4章](#4-データの取得と整形手順)） |

## 3. PDFのステップと使うデータ

| PDFのステップ | 使うデータ | 系統B（CSV）で使う列 |
|---|---|---|
| 前処理：分析対象（年代×性別・回答者5人以上、680市町村）を決める | A：主観データ・客観データ | — |
| ステップ0：市区町村の類型を決める（k-means、3類型） | B：類型6変数 | `人口`、`人口密度`、`高齢化率`、`財政力指数`、`第1次産業就業者割合`、`可住地面積割合`（人口と人口密度は対数をとる） |
| ステップ1：和歌山の立ち位置（全国の中の順位） | A：幸福度・主観24分野・客観24分野 | — |
| ステップ2：ターゲットの市 | A ＋ 各市の総合計画（データではなく公式サイトを確認） | — |
| ステップ3：上げる分野（寄与度LMG） | A：幸福度・主観24分野（年代×性別の行） | — |
| ステップ4：下振れの場所（主観−客観） | A：主観24分野・客観24分野 | — |
| 改善候補①：環境整備で上がる分野か | A：主観 ＋ B：個別KPI | 個別KPI 28本（[5.2](#52-個別kpi28本)） |
| 改善候補②：伸ばす数値の候補 | A：幸福度 ＋ B：個別KPI | 個別KPI 28本 |
| ステップ5：改善候補を絞る（固定効果モデル） | A：主観・幸福度・客観スコアの年度ごとの値（2023〜25年度） | —（個別KPIは1時点しかないため、PDFでも使っていない） |
| ステップ6：改善余地の確認 | A：客観スコア（2023→2025年度） | — |

**AとBを結合するときの注意**
- Bのキーは5桁の市区町村コードです。Aにはコードがなく、`地域ID`（ダッシュボード独自の番号）と名前の列しかありません。そのため `都道府県` と `市区町村` の名前で結合します。
- Aの政令市は「札幌市全域」のように名前に「全域」が付いています。外してから照合してください。
- PDFの分析対象は、政令市の区と東京23区を除いた市町村です。Bの東京23区（`区分`＝特別区）は除いて使います。

### 4.1 フォルダ構成

番号は「出典フォルダ」と「取得スクリプト」で同じにしています。

    ├─ 01_download/NN_出典名.py   取得（データと同じ番号）

### 4.2 実行手順

`set_up` 直下の `.venv` を使います。取得 → 整形の順で実行します。

```bash
cd C:/Users/鈴木啓太/GitHub/set_up
source .venv/Scripts/activate        # Windows の Git Bash の場合
pip install requests pandas openpyxl xlrd pymupdf pypdf

# 1) 取得（01〜12。順番は問わない）
for f in _tmp_wakayama_competition/05_scripts/01_download/*.py; do python "$f"; done

# 2) 整形
python "_tmp_wakayama_competition/05_scripts/02_build/01_市区町村別KPI表の作成.py"
deactivate
```

- 取得には数分かかります（合計約200MB。最大は公共施設状況調の約45MB）。
- 次の2つは公開元が随時更新するため、再取得すると値が変わることがあります。

## 6. PDFの値との照合結果

PDFに数値が載っている市（和歌山市・田辺市・橋本市・岩出市・海南市・紀の川市）で照合しました。

| 結果 | 変数 |
|---|---|
| 一致（小数点以下まで） | 類型6変数すべて、高齢単身世帯割合、拡大家族世帯割合、完全失業者数_人口比、完全失業率、歩道設置率、駅バス停／公園緑地／保育所の徒歩圏人口カバー率、住宅当たり延べ面積、実質公債費比率、歳出総額の教育費割合、人口あたり自殺者数 |
| 一致しない | 健康寿命（近似）：PDFより0.1〜0.35歳低い（下の表） |
| PDFに数値がなく未照合 | 上記以外の個別KPI |

照合の結果、当初の想定から年度・出典を変えたものがあります。
- 歳出総額の教育費割合：2022年度ではPDFと合わず、2021年度の決算で一致しました（和歌山市7.19、田辺市7.39）。
- 財政力指数：2021年度版ではなく、2023年度版で一致しました（和歌山市0.77、岩出市0.61）。
- 高齢化率：国勢調査2020ではなく、住民基本台帳2024年1月で一致しました（和歌山市31.0、田辺市34.4）。

健康寿命（近似）は、「要介護2以上を不健康とし、生命表に当てはめる方法（サリバン法）」で計算しています。ほかの3通り（要介護1以上、要支援を含む、要介護3以上）も試しましたが、この方法が最もPDFに近い値でした。PDF側の近似方法は分かりません。

## 7. 再現上の限界と注意

- **個別KPIは32本中28本です。** PDFには「個別KPI 32本」とありますが、名前が分かるのは28本です。残り4本は特定できていないため、改善候補②の「説明力8%→35%」はそのままでは再現できません。
- **データの年がそろっていません。** 都市モニタリングシートは令和6年版しか公開されておらず、保育所（2015年）・公園（2011年）の徒歩圏カバー率は古いデータです。
- **空欄が多い変数があります。**
  - 住宅の2つのKPI：住宅・土地統計調査は市と人口1.5万人以上の町村だけが対象のため、値があるのは1,059市区町村です。
  - 福祉施設・保育所・公園緑地の徒歩圏人口カバー率：元データの時点で空欄が300〜400あります。
  - 健康寿命：介護保険を広域連合で運営する市町村や、生命表が作られていない小規模な町村など、約220市区町村が空欄です。
- **NPOの数は約1%漏れています。** 活動中の法人の約1%（508件）は、住所から市区町村を特定できず、数に入っていません。
- **再取得すると値が変わる変数があります。** NPO法人とウォーカブル推進都市は、取得した日時点の値です。
- **再現できない判断があります。** ステップ2の総合計画との照合は、データではなく各市の公式サイトを読んで判断しています。
