## 1. 目的と結論

**目的**：和歌山市の住民の幸福度（0〜10点）を上げるために、デジタル庁の地域幸福度データの分析から、既存データで最も妥当性が高いと考えられる施策仮説を設計し、実施後に効果を確かめる方法まで示す。

**結論**：和歌山市の男性・70代以上は、24分野の生活満足が全体的に低く、その共通の背景として「外出・移動の環境」が最も有力な仮説である（原因とまでは言えない）。本施策案は、**「元気70 おでかけプロジェクト（仮称）」**として、次の4つを1つの仕組みにまとめて実施することを提案する。

1. **届ける**：免許返納・配偶者との死別・ひとり暮らしなど、外出が減りやすいきっかけの時点で、本人に直接声をかける
2. **足**：既存の「元気70パス」を土台に、免許返納者と交通不便地域の70代以上に、バス・デマンド型乗合交通を安く使える「おでかけパス」を上乗せし、デマンド型乗合交通の地区を広げる
3. **道**：駅・バス停から行き先までの経路に、ベンチ・日陰・段差解消を集中させた「休める歩行ルート」を整える
4. **行き先と役割**：公園・公民館・通いの場に、男性が経験を生かして教える・運営する・運転するなどの「役割がある場」をつくる

本施策案は、既存データから最も妥当と考えられる**施策仮説**である。分析は市町村どうしの比較で見た関係で、施策を行えば幸福度が上がるという因果関係は示せていない。そのため、施策を地区ごとに段階的に始め、**施策 → 中間指標（Why）→ 生活満足 → 幸福度**のどこまで変化したかを確かめながら進める（8章）。

### 2.2 データと用語（概要。詳細は3章）

**データ**
- デジタル庁「地域幸福度（Well-Being）指標」の市区町村別データ（2023〜26年度版）。幸福度（0〜10点）と、24分野の生活満足（主観スコア）が、市区町村×年度×年代×性別の単位である［D1］。
- 分析に使った行：2023〜26年度版、政令市は区ではなく市全体、同じ年度の客観スコアがそろう、回答者5人以上の行。全国703市町村・18,638行。
- 年代は10歳きざみで、80代以上は70代とまとめて「70代以上」とした。性別×年代で12区分になる。
- 外部の変数（駅・バス停の近さ、歩道、公園、就業率など）：都市モニタリングシート、国勢調査2020などの公的統計［D2］。

**用語**

| 用語 | 意味 |
|---|---|
| 類型 | 人口・人口密度・高齢化率・財政力指数・第1次産業就業者割合・可住地面積割合で、全国の市町村を3つ（都市部・地方の中心都市・農山村の小都市）に分けたもの（k-means法）。和歌山市は都市部（268市町村）。すべての比較は、同じ類型の中で行う |
| 平均との差 | 各行の値から、同じ「類型×年度×年代×性別」の行の平均（回答者数で重みづけ）を引いた値。0なら同じ類型の同じ区分の平均と同じ |
| 寄せた値 | 市×区分の「平均との差」を4年度分まとめ、回答者が少ないほど強く0（平均）に寄せた値（経験ベイズ）。回答者が少ないために偶然低く出た値を割り引く |
| 誤差を見込んだ値 | 寄せた値＋1.28×標準誤差。0未満なら、90%の確率で本当の値が平均より低い（「明らかに低い」） |
| 全体の満足 | 24分野の主観スコアの「平均との差」を24分野で平均した値 |
| 相対の差 | 分野の「平均との差」から、全体の満足を引いた値。マイナスなら、その人たちの中でも相対的に低い分野 |
| 説明力 | 全国の行で、区分ごとに幸福度を24分野の満足で説明する回帰（Elastic Net）を行い、各分野の係数の大きさを合計100%の割合にしたもの。均等割りは100÷24＝4.2% |
| 標準偏差（SD） | ばらつきの大きさ。「和歌山市の位置が−1.5SD」なら、同じ類型の平均より標準偏差1.5個分低い |

### 前処理

#### 前.1 地域の単位

- **政令市は「○○市全域」の行を使い、区の行は使わない。** デジタル庁のデータには、政令市の区ごとの行と、市全体の「○○市全域」の行の両方がある。全域の行は区の回答者を合わせた行のため、区の行と全域の行の両方を使うと、同じ回答者を二重に数える。
- **本分析が区の行ではなく全域の行を残すのは、客観スコアや個別KPIが区ごとにないため。** 区の行（171区）の66%は回答者5人以上の条件（前.3）を満たす。しかし、区の行は客観24分野のスコアがすべて空欄で、類型の6変数や個別KPIも、政令市については市全体の値しかない。本分析が区の行を使うと、類型（ステップ0）も、変数による原因候補の探索（ステップ6）もできない。
- **本分析は東京23区を区ごとに使う。** 東京23区の各区は独立した自治体（特別区）で、客観スコアも個別KPIも区ごとにあるため。

#### 前.2 年度（2023〜26年度版）

- **本分析は、幸福度データの2023〜26年度版の4年分を使う。**

#### 前.3 回答者数の下限（5人以上）

- **本分析は、回答者が5人以上の行だけを使う。**
  - 回答者が1人の行では、読み手は、回答者1人の考えが、同じ市町村の同じ年代×性別の人たちの中でどれくらい一般的かが分からない。本分析は、複数人が答えた行に絞ることで、1人の回答に引っぱられた行の値を除く。
  - 一方で、本分析が回答者数の下限を高くするほど、人口の少ない市町村や回答者の少ない年代の行が分析から落ち、人口の少ない市町村の住民の声が分析に反映されなくなる。本分析は、「複数人が答えた」と言える小さい値として、回答者数の下限を5人とした。

#### 前.4 データのフィルタリング

本分析は、デジタル庁のデータの年代×性別の行に、次の4つの条件をすべてかけて、分析に使う行を決めた。

1. 2023〜26年度版の行（前.2）
2. 政令市は区の行を除き、市全体の行を使う（前.1）
3. 回答者が5人以上の行（前.3）
4. 同じ年度の客観24分野のスコアがすべてそろう行（前の版の分析と同じ行にそろえ、類型・ターゲットの市・説明力の結果をそのまま使うため）

#### 前.5 性別×年代の区分

本分析は、前.4の4つの条件をかけた後の行のうち、次の2つの年代の扱いを変えた。

- **本分析は、80代以上の行を70代の行とまとめて「70代以上」の区分にする**：前.4の4つの条件をかけると、80代以上の行は全国で女性55行・男性160行しか残らず、標本が足りないため。
- **本分析は、10代の行を使わない**：前.4の4つの条件をかけると、10代の行は全国で3行しか残らないため。

#### 前.6 市×区分の値を類型の平均に寄せる（回答者数の少なさの扱い）

1つの市の1つの区分の回答者は、4年分を合わせても数人〜百数十人しかいない。回答者が少ない区分では、たまたま点数の低い人が何人か答えただけで、区分の平均点が大きく下がる。そのため、本分析は市×区分の値を、次の3つの手順で回答者の少なさを割り引いてから使う。

1. **値を類型の平均に寄せる（経験ベイズ）**：本分析は、市×区分の値（同じ類型・同じ区分の平均との差。0なら類型の平均と同じ）に、0〜1の「信頼度」をかける。信頼度は、区分の回答者が多いほど1に近く、少ないほど0に近い。
   - 信頼度 ＝ τ² ÷（τ² ＋ σ² ÷ 回答者数）。τ²は市町村どうしの本当の差の大きさ、σ²は1人ひとりの回答のばらつきで、どちらも区分ごとに全国の行から推定する。
   - 例：和歌山市の幸福度（ステップ3）は、男性・50代（回答者144人）では信頼度0.31で+0.04→+0.01と元の値に近いまま残り、女性・20代（回答者6人）では信頼度0.04で−1.36→−0.06と大きく0に寄る。
2. **誤差を見込んだ値を使う**：寄せた値にも不確かさが残るため、本分析は標準誤差（値の不確かさの幅）も出す。ステップ2・3・4Bでは「寄せた値＋1.28×標準誤差」を「誤差を見込んだ値」として使う。誤差を見込んだ値が0未満なら、90%の確率で、本当の値が同じ類型の平均（0）より低い。本分析は、誤差を見込んだ値が0未満の組を「明らかに低い」とする。
3. **回答が1年度しかない区分は使わない**（ステップ2・3）：1年度だけの回答は、回答した年度にたまたま答えた少数の人の偏りを反映しやすいため、本分析は、回答が2年度以上ある区分だけを使う。

### ステップ0　市区町村の類型を決める

#### 0.1 背景
人口規模や都市化の度合いが違う市町村の主観スコアを、条件をそろえずに並べると、市町村どうしの主観スコアの差の多くが「都市か地方か」で決まってしまい、施策で埋められる差が見えなくなる。

#### 0.2 目的
本分析は、地域の条件が似た市町村を類型にまとめ、以降のステップで「同じ類型の市町村の中で比べる」ための基準をつくる。

#### 0.3 解き方

1. **6変数をそろえる**：本分析は、人口（対数）、人口密度（対数）、高齢化率、財政力指数、第1次産業就業者割合、可住地面積割合の6変数を使う。6変数は単位が違うため、本分析は6変数をそれぞれ平均0・ばらつき1に標準化する。
2. **類型の数をエルボー法で決める**：類型の数kを1〜12まで変えてk-means法（近い市町村どうしをk個のまとまりに分ける方法）で分け、kごとに「類型の中のばらつき（クラスタ内平方和）」を計算する。kを増やすと、類型の中のばらつきは必ず減る。本分析は、ばらつきの減り方が急に緩やかになる点（エルボー）を、類型の数として自然な点とみなす。本分析は、k=1の点とk=12の点を結ぶ直線から最も離れた点をエルボーとし、エルボーはk=3になった。
3. **703市町村を3つに分ける**：本分析は、k=3でk-means法をかけて703市町村を3つの類型に分け、類型に入る市町村の人口密度の中央値が高い順に「都市部」「地方の中心都市」「農山村の小都市」と名前を付けた。

#### 0.4 方法を選んだ理由

- **6変数で暮らしの条件を6つの面から1つずつ表す**：6変数は、規模（人口）、まとまり（人口密度）、年齢構成（高齢化率）、財政の余力（財政力指数）、産業（第1次産業就業者割合）、地形（可住地面積割合）を表す。
- **類型の変数に幸福度や主観・客観スコアを入れない**：本分析が類型の変数に幸福度や主観スコアを入れると、「主観スコアの低い市どうし」が同じ類型にまとまり、同じ類型の中で比べたときの主観スコアの差が最初から消えてしまう（結果の先取りになる）。
- **人口と人口密度は対数にする**：大都市の人口・人口密度はほかの市町村より桁違いに大きく、本分析が対数にしないと、少数の大都市の値だけで類型の分け方が決まってしまうため。
- **エルボー法で類型の数を決める**：類型を細かくするほど1つの類型に入る市町村が減り、各市が比べる相手が少なくなる。本分析は、類型の数を、ばらつきの減り方が鈍る点で止めることで、似た市町村をまとめつつ、比べる相手の数を保つ。

- **地方の中心都市**（280市町村）：橋本市・岩出市
- **農山村の小都市**（155市町村）：海南市・田辺市・紀の川市

### ステップ1　区分ごとの立ち位置

#### 1.1 背景
市の幸福度・主観24分野平均を、性別・年代を分けずに市の回答者全員で平均した値（市全体の平均）だけで見ると、同じ市の中に点数の高い層と低い層があっても、高い層と低い層の点数が打ち消し合い、低い層が見えなくなる。市が施策を向ける層を決めるには、本分析は、性別×年代の区分ごとに、各市の点数が同じ類型の中でどの位置にあるかを知る必要がある。

#### 1.2 目的
本分析は、和歌山6市の幸福度・主観24分野平均を、性別×年代の区分ごとに、同じ類型・同じ区分の全国の市町村と比べ、同じ市の中に低い層と高い層が混ざっているかを確かめる。

#### 1.3 解き方

1. **比べる土台をそろえる**：本分析は、各行の幸福度・主観24分野平均から、同じ「類型×年度×年代×性別」の行の平均（回答者数で重みづけ）を引く。差が0の行は、行の値が、同じ類型・同じ年度・同じ年代×性別の平均と同じであることを示す。
2. **市×区分の値にする**：本分析は、市×区分ごとに、手順1の差を4年度分、回答者数で重みづけて平均し、類型の平均に寄せる（前.6の手順1）。
3. **類型内%を出す**：市×区分の寄せた値が、同じ類型・同じ区分の全国の市町村の寄せた値の中で、下から何%の位置にあるかを「類型内%」とする（0に近いほど低く、50が真ん中、100に近いほど高い）。
4. **弱い層・強い層を決める**：本分析は、幸福度と主観24分野平均の類型内%がどちらも25以下の区分を「弱い層」、どちらも75以上の区分を「強い層」とする。

#### 1.4 方法を選んだ理由

- **同じ類型・同じ年代×性別の平均を引く**：幸福度も主観スコアも、都市か地方か・年代・性別で水準が違う。本分析が平均を引いてそろえないと、「高齢の男性の回答者が多い市は点数が低い」のような回答者の構成の差を、市の弱さと取り違える。
- **類型内%を寄せた値で出す**：回答者が少ない区分の値は、偶然で上下の端に出やすい。本分析は、類型の平均に寄せた値で類型内%を出すことで、回答者が少ないだけの区分が最下位・最上位になることを防ぐ。
- **幸福度と主観24分野平均の両方で弱い層・強い層を決める**：幸福度は「暮らし全体にどれくらい満足しているか」を1問で聞いた点数、主観24分野平均は住宅・健康・仕事など24分野の満足を平均した点数である。本分析は、両方が低い区分だけを弱い層とすることで、暮らし全体の満足でも、分野ごとの満足でも低い区分を選ぶ。片方だけが低い区分は、1つの物差しでたまたま低く出た可能性がある。
- **25と75で区切る**：類型内%の25と75は、同じ類型・同じ区分の全国の市町村を、値の低い順に4等分したときの、下から4分の1と上から4分の1の境目である。本分析は、真ん中の半分（類型内%が25〜75）を「同じ類型の中でふつう」とみなし、下の4分の1を弱い層、上の4分の1を強い層とする。
- **弱い層と強い層を並べて示す**：同じ市の中に弱い層と強い層の両方があれば、市全体の平均では弱い層の低さが強い層の高さで打ち消される（1.1）。本分析は、弱い層と強い層を市ごとに並べることで、打ち消しが実際に起きうる市を示す。

### ステップ2　ターゲットの市

#### 2.1 背景
本分析が6市すべてについて、層・分野・数値まで同じ深さで調べるのは難しい。本分析は、重点的に調べる市を2市に絞る必要がある。本分析は、データ（市×性別×年代×分野の主観スコア＝定量）と、各市の事情（総合計画の中身＝定性）の両方から2市を選ぶ。データだけで選ぶと、市自身が課題と認識していない分野の市や、総合計画を作り終えたばかりの市を選び、本分析の提案が市の施策につながらないおそれがあるためである。

#### 2.2 目的
本分析は、重点的に分析・施策検討する市（ターゲットの市）を2市決める。本分析は、幸福度が最も低い市を選ぶのではなく、主観スコアの課題が多く、かつ施策につなげる意義と実行可能性が高い市を選ぶ。

#### 2.3 解き方

1. **性別×年代×分野ごとの値を出す**：本分析は、各行の主観24分野の点数から、同じ「類型×年度×年代×性別」の行の平均を引き、市×性別×年代×分野ごとに4年度分を回答者数で重みづけて平均して、類型の平均に寄せる（前.6の手順1）。寄せた値が0なら同じ類型の平均と同じ、マイナスなら平均より低い。1つの市について、「性別×年代（最大12）×24分野」の組ができる。
2. **定量：明らかに低い組の割合を出す**：本分析は、次の3つをすべて満たす組を「明らかに低い組」とし、市ごとに、調べた組（回答が2年度以上ある性別×年代 × 24分野）に占める明らかに低い組の割合を出す。明らかに低い組の分野を「明らかに低い分野」と呼ぶ。
   - **条件1　同じ類型の中で下位5%に入る**
     - 目的：同じ類型の市町村と比べて、とりわけ低い組だけを拾う。平均より少し低いだけの組は、どの市にも多くあり、市どうしの違いにならない。
     - 中身：市×性別×年代×分野の寄せた値が、同じ類型・同じ性別×年代の全国の市町村の寄せた値の中で、下から5%以内（類型内%が5以下）。
     - 例：和歌山市・女性・40代・デジタル生活は、都市部の268市町村の中で低いほうから1番目（類型内%は0.4）で、条件1を満たす。
   - **条件2　誤差を見込んでも、同じ類型の平均より低い**
     - 目的：回答者が少ない組の、偶然の低さを除く。回答者が少ない組では、たまたま点数の低い人が何人か答えただけで、寄せた値が大きく下がる。
     - 中身：本分析は、寄せた値に「標準誤差の1.28倍」を足した値が0未満の組だけを残す。標準誤差は、回答者が少ないために寄せた値がどれくらい上下に揺れうるかの幅である。「本当の値は、寄せた値より揺れの分だけ高かったかもしれない」と高めに見積もっても、なお同じ類型の平均（0）より低ければ、偶然では説明しにくい低さと判断する。1.28倍は、本当の値が高めの見積もりより下にある確率が90%になる倍率である（前.6の手順2）。
     - 満たす例：和歌山市・女性・40代・デジタル生活（回答者69人）：寄せた値−18.9点、標準誤差4.5点 → −18.9＋1.28×4.5＝−13.2点で、高めに見積もっても0未満のため、明らかに低い組になる。
     - 満たさない例：橋本市・女性・40代・地域とのつながり（回答者41人）：寄せた値−4.3点、標準誤差4.3点 → −4.3＋1.28×4.3＝+1.2点。橋本市・女性・40代・地域とのつながりは類型内%が2.9で条件1を満たすが、高めに見積もると0以上になり、偶然の低さを否定できないため、明らかに低い組に入れない。
   - **条件3　回答が2年度以上ある**
     - 目的：1つの年度にたまたま答えた少数の人の偏りを除く（前.6の手順3）。
3. **定性：2つの観点で6市の総合計画を比べる**：本分析は、6市の総合計画を、次の2つの観点で比べる。
   - **観点A　市自身も課題としているか**：明らかに低い分野のうち、総合計画が現状の弱み・低下・不足として書いている分野の割合。割合が大きい市ほど、データが示す低さを市自身も問題と考えており、本分析の提案を受け止めやすい。
   - **観点B　本分析の提案が次期計画に入る時期か**：総合計画の策定の段階。次期計画をこれから作る市ほど、本分析の提案を計画に反映しやすい。総合計画を作ったばかりで、次期計画に着手していない市は「入りにくい」とする。
4. **判定**：本分析は、明らかに低い組の割合が大きい順に6市を並べ、観点A（総合計画が課題とする分野の割合が75%以上）と観点B（入りうる）をどちらも満たす市を、上から2市選ぶ。1つ目の市を主ターゲット、2つ目の市を副ターゲットとする。

#### 2.4 方法を選んだ理由

- **性別×年代ごとの値で比べる**：市全体の平均（性別・年代を分けない平均）では、一部の層の低さが、ほかの層の高さで打ち消される（ステップ1）。本分析は、性別×年代ごとの値を見ることで、どの市に低い層・分野が多いかを知る。
- **組の数ではなく割合で比べる**：回答者5人以上の行がない性別×年代があるため、市によって調べられる組の数が違う（168〜240）。本分析は、明らかに低い組の割合で比べることで、組の数の違いに左右されずに6市を比べる。
- **定量で並べてから定性で確かめる**：ターゲットの市は、本分析が層・分野・数値まで掘り下げる市のため、まずデータで低さが多い市である必要がある。そのうえで、本分析は、定性の2つの観点で、提案を受け止めて施策にできる市かを確かめる。
- **観点Aの基準を75%とする**：明らかに低い分野の4分の3以上を市自身も課題としていれば、データと市の認識がおおむね一致すると考える。

### ステップ3　Who：幸福度が低い層

#### 3.1 背景
本分析の目的は幸福度を上げることである。市全体の幸福度の平均だけを見ると、同じ市の中で幸福度が低い層が、ほかの層の高さに打ち消されて見えなくなる（ステップ1）。市が施策を向ける層を決めるには、本分析は、ターゲットの市の性別×年代の区分ごとに、幸福度そのものが同じ類型の中で低いかを確かめる必要がある。

#### 3.2 目的
本分析は、ターゲットの市ごとに、重点的に検証する性別×年代の区分（**Who**）を決める。幸福度が有意に低い区分を探すのではなく、幸福度の推定値が最も低く、検証する価値が最も高い区分を選ぶ。

#### 3.3 解き方

1. **比べる土台をそろえる**：本分析は、各行の幸福度から、同じ「類型×年度×年代×性別」の行の平均（回答者数で重みづけ）を引く。
2. **市×区分の値にして、類型の平均に寄せる**：本分析は、市×区分ごとに、手順1の差を4年度分、回答者数で重みづけて平均し、回答者が少ないほど強く0（同じ類型・同じ区分の平均）に寄せる（前.6の手順1）。
3. **誤差を見込んだ値を出す**：本分析は、寄せた値＋1.28×標準誤差を「誤差を見込んだ値」とする。誤差を見込んだ値が0未満なら、本分析は、市×区分の幸福度を「明らかに低い」とみなす（前.6の手順2）。
4. **Whoを選ぶ**：本分析は、回答が2年度以上ある区分の中で、寄せた値（幸福度の推定値）が最も低い区分をWhoの候補とし、ステップ4Bで24分野の満足も全体的に低いことを確かめて、重点的に検証するWhoとする。

#### 3.4 方法を選んだ理由

- **寄せた値で比べる**：回答者が少ない区分ほど、たまたま点数の低い人が数人答えただけで、生の値が大きく下がる。本分析は、寄せた値で比べることで、回答者が少ないだけの区分をWhoに選ぶことを防ぐ。
- **「明らかに低い」を条件にしない**：幸福度は、同じ区分の中で市町村ごとの本当の差が小さく、寄せる度合いが強い。本分析が「明らかに低い」を条件にすると、どの市でもWhoを選べない。本分析は、寄せた値が最も低い区分を「最も低い候補」としてWhoに選び、不確かさ（95%の範囲・誤差を見込んだ値）を並べて示す。
- **回答が2年度以上ある区分に限る**：1年度だけの回答は、その年にたまたま答えた少数の人の偏りを反映しやすい（前.6の手順3）。

### ステップ4A　区分ごとの説明力

#### 4A.1 背景
市が主観24分野すべての主観スコアを同時に上げるのは難しい。主観スコアを上げても幸福度が上がらない分野に市が力を注いでも、住民の幸福度は上がらない。また、幸福度とつながる分野は、性別や年代によって違う可能性がある（例：高齢者は健康、子育て世代は子育て）。

#### 4A.2 目的
本分析は、性別×年代ごとに、**どの分野の満足を上げれば、住民の幸福度が上がりやすいか**を知る。ステップ4Bで、本分析は、Whoの区分の説明力を使ってWhatを選ぶ。

#### 4A.3 解き方

幸福度が上がりやすい分野を知るために、本分析は、全国の行で「ある分野の満足が高い行ほど、幸福度も高いか」を、24分野を同時に入れた回帰で調べる。回帰で幸福度の差を大きく説明する分野（説明力が大きい分野）ほど、満足が上がったときに幸福度も上がりやすい分野とみなす（回帰が示すのは全国の行どうしを比べた関係で、満足を上げたときに幸福度が上がることを確かめたものではない）。
本分析は、性別×年代の12区分（前.5）ごとに回帰を1本ずつ推定する。1本の回帰には、対象の区分に当たる全国の「市町村×年度」の行を使う。1本の回帰の手順は次のとおり。

1. **比べる土台をそろえる**：本分析は、各行の幸福度と主観24分野の点数から、同じ「類型×年度×年代×性別」の行の平均（回答者数で重みづけ）を引く。
2. **標準化**：本分析は、幸福度と主観24分野の各分野の点数を、平均0・ばらつき1にそろえる。
3. **Elastic Net回帰**：本分析は、幸福度 ＝ Σ β分野 × 主観分野 を、回答者数で重みづけして推定する。Elastic Net回帰は、普通の重回帰（最小二乗法）に、係数の大きさへの罰則（L1＝Lasso：効かない分野の係数を0にする、L2＝Ridge：似た分野どうしで係数を分け合う）を加えた回帰である。
4. **罰則の強さを交差検証で決める**：本分析は、罰則の強さ（alpha）とL1の割合（l1_ratio：0.1〜1.0の7通り）を、市町村単位の5分割交差検証（市町村ごとに5組に分け、4組で学習して残り1組を当てる）で、当てはまりが最もよい組に決める。
5. **説明力の取り分**：本分析は、各分野の係数の絶対値を、全分野の合計が100%になる割合に直し、「取り分」とする。係数がマイナスの分野（主観スコアが高いほど幸福度が低い分野）の取り分を、本分析はステップ4Bでマイナスの取り分として扱う。

#### 4A.4 方法を選んだ理由

- **区分ごとに推定する**：本分析が全区分の行をまとめて1本の回帰で推定すると、どの区分にも同じ取り分が当てはめられ、区分ごとの取り分の違いが見えない。
- **類型ごとには回帰を分けない**：1つの区分の行は全国でも百数十〜2,000行あまりで、本分析がさらに3類型に分けると、1本の回帰に使う行が少なくなりすぎる。本分析は、類型の違いを、手順1で平均を引いてそろえる。
- **平均を引いて比べる土台をそろえる**：平均を引かずに回帰すると、回帰は分野の効き方ではなく「特定の属性の人は幸福度も主観スコアも高い」という差を拾ってしまう。本分析は、同じ条件の人たちの中で、主観スコアが高い人ほど幸福度も高いかだけを見る。
- **標準化する**：分野ごとに点数のばらつきが違うため、本分析が標準化しないと、係数の大きさを分野どうしで比べられない。
- **回答者数で重みづける**：回答者が多い行ほど、行の平均点の揺れが小さく、行の値を信頼できるため。
- **普通の重回帰ではなくElastic Netを使う**：主観24分野は互いの相関が強く、普通の重回帰では係数の大きさや向きが、データの少しの違いで大きく変わる。Lassoだけでは似た分野のどちらか一方だけが残り、Ridgeだけでは効かない分野の係数が0にならない。Elastic NetはLassoとRidgeを組み合わせて、効かない分野を0にしつつ、似た分野で係数を分け合う。
- **市町村単位で交差検証する**：同じ市町村の別年度・別の年代の行は、値が似ている。同じ市町村の行が学習とテストの両方に入ると、本分析は回帰の当てはまりを高く見積もってしまう。
- **取り分（%）にする**：本分析は、係数を合計100%の割合にすることで、分野どうしを比べやすくし、ステップ4Bの基準線（24分野の均等割り 100÷24＝4.2%）とも比べられるようにする。

### ステップ4B　What：主観スコアの低さの構造

#### 4B.1 背景
Whoの幸福度を上げるために市が手を打つ先は、Whoの主観スコアが低い分野である。ただし、Whoがどの分野も低めに答えている場合、特定の分野だけを選んで手を打っても、Whoの低さの一部にしか届かない。そのため、本分析は、分野を1つに絞る前に、Whoの低さが特定の分野に偏るか、多くの分野に共通するかを確かめる必要がある。

#### 4B.2 目的
本分析は、Whoの主観スコアの低さの構造（多くの分野に共通する低さと、分野に固有の低さ）を明らかにし、Whyを探す対象を決める。

#### 4B.3 解き方

1. **全体の満足**：本分析は、各行の主観24分野の差（同じ「類型×年度×年代×性別」の平均との差）を24分野で平均し、市×区分ごとに寄せる（前.6）。寄せた値＋1.28×標準誤差（誤差を見込んだ値）が0未満なら、Whoの24分野の満足は全体として明らかに低い。
2. **分野ごとの低さ**：本分析は、分野ごとの主観スコアの差も同じ方法で寄せ、誤差を見込んでも0未満の分野を「明らかに低い」とする。
3. **分野に固有の低さ（相対的な低さ）**：本分析は、各行の分野の差から24分野の差の平均を引いた値（相対の差）を同じ方法で寄せる。誤差を見込んだ相対の差が0未満の分野は、Whoの中でもとりわけ低い分野である。
4. **固有Whyの対象**：本分析は、説明力（ステップ4A）が24分野の均等割り（100÷24＝4.2%）より大きく、相対の寄せた差が0未満の分野を、固有Why（ステップ8）で原因を探す分野とする。固有Whyは探索のため、本分析は相対の差に誤差を見込まない。

#### 4B.4 方法を選んだ理由

- **全体の満足を先に見る**：全体の満足が明らかに低ければ、Whoの低さは多くの分野に共通する要因（共通Why）から来ている可能性が高い。本分析は、共通の低さを1つの結論として扱う。
- **相対の差で分野に固有の低さを見る**：Whoの主観スコアの差には、全体の低さと分野に固有の低さが重なっている。相対の差は全体の低さを除くため、分野に固有の低さだけを表す。
- **説明力で固有Whyの対象を絞る**：分野に固有の低さがあっても、幸福度とのつながりが小さい分野の原因を探しても、幸福度の目的には届きにくい。

### ステップ5　目的との接続：全体の満足と幸福度の連動

#### 5.1 背景
ステップ4Bで、Whoの低さは多くの分野に共通していた。全体の満足を上げることが幸福度を上げることにつながるかを確かめるには、市町村どうしの比較（地域の気風など、市町村ごとに変わらない違いが混ざる）だけでなく、同じ地域の中での変化を見る必要がある。

#### 5.2 目的
本分析は、同じ地域×性別×年代の中で、全体の満足（主観24分野平均）が上がった年に幸福度も上がっていたかを確かめ、全体の満足を改善の対象にする意味があるかを点検する。

#### 5.3 解き方

本分析は、全国の行のうち、2年度以上の行がある地域×性別×年代を使い、2つのモデルを推定する（回答者数で重みづけ、標準誤差は地域ごとのクラスタ）。

- **① 固定効果**：幸福度 ＝ β × 主観24分野平均 ＋ 地域×性別×年代の効果 ＋ 年度の効果。地域×性別×年代ごとに変わらない違いを取り除き、同じ地域×性別×年代の中で、年ごとの変化どうしを比べる。
- **③ 参考：市町村どうしの比較**：①から地域×性別×年代の効果を除いたもの。

係数βは、主観24分野平均が行どうしの標準偏差1つ分高いときの、幸福度（0〜10点）の差である。本分析は、①の結果を因果ではなく「同じ地域の中での連動」として扱う。同じ回答者が幸福度と24分野の両方に答えているため、気分のよい人がどちらにも高く答える影響や、幸福度が高い人ほど満足しやすいという逆向きの影響は取り除けない。

### ステップ6　Whyの探し方

#### 6.1 背景
主観スコアが低い原因を知るには、本人が何に不満を持つかを聞くのが近道である。しかし、デジタル庁のデータには分野ごとの点数しかなく、設問ごとの点数も、本人の状況もない。そのため、本分析は、まず外部の変数（統計の値）から原因の候補を探し、施策の実施後のPoC（8章）の調査で確かめる。

#### 6.2 目的
本分析は、共通Why・固有Whyに共通する、原因の候補の探し方（Why①）と確かめ方（Why②）を決める。

#### 6.3 解き方

**目的変数**（どれも、同じ「類型×年度×年代×性別」の平均との差）

- 共通Why：全体の満足（主観24分野の差の平均）
- 固有Why：分野の相対の差（分野の差 − 24分野の差の平均）。全体の満足と一緒に動く部分を除き、分野だけの低さを見る。

**Why①　探索**

1. **データ**：全国の男性・70代以上の行（2,195行、665市町村）を使う。変数からも、同じ「類型×年度×年代×性別」の平均を引き、類型の中の標準偏差1つ分あたりにそろえる。本分析が見るのは、「和歌山市の男性・70代以上は、同じ類型のほかの市町村の男性・70代以上と比べて、なぜ低いか」である。
2. **変数を1本ずつ入れた回帰**：目的変数 ＝ β×変数（回答者数で重みづけ、標準誤差は市町村ごとのクラスタ）。βが想定の向きで、偽発見率で補正したq値が0.10未満なら「関連あり」とする。
3. **和歌山市の位置と予測寄与**：和歌山市の変数の値が、同じ類型の平均から標準偏差いくつ分離れているか（和歌山市の位置）を出し、β×和歌山市の位置を**モデル上の予測寄与**とする。
4. **原因候補**：関連あり、かつ予測寄与がマイナス（和歌山市の値が、目的変数を下げる向きにある）。

**Why②　検証**

- **B　他の要因の代わりではないか**：類型を決めた6変数（人口・人口密度・高齢化率・財政力指数・第1次産業就業者割合・可住地面積割合）をモデルに足し、係数がどれだけ残るか（残る割合）を見る。0.5以上なら通過。
- **C　測っていない要因への強さ**：Osterの方法で、測っていない要因が6変数と同じ強さで効くと仮定したとき（R²の上限はBのR²の1.3倍）の係数β*を出す。β*の向きが想定どおりなら通過。
- **残った候補**：原因候補のうち、BとCを通過した変数。
- **A　予測寄与の合計**：残った候補をまとめて入れたモデルで予測寄与の合計を出し、和歌山市の実際の差と並べる。予測寄与はモデルの上での対応で、原因として説明した点数ではない。

### 4.3 重点Whyの決定

- **重点Why（最も有力な仮説）：外出・移動の環境**。4つの観点すべてで最も高い評価（総合12点）。共通Whyで3変数が残り、和歌山市は3つの変数のどれも同じ類型（都市部、268市町村）の中で下位にある（5章の表5-1）。24分野中21分野の満足と関連し、市が道路・交通・公園の施策で直接動かせる。

- **2位は仕事・役割、所得、家族・同居が同点（9点）**。本施策案は、次の理由で扱いを分ける。

  - **仕事・役割 → 補う重点（外出の「目的」として組み合わせる）**：固有Whyで3分野（地域とのつながり、文化・芸術、雇用・所得）に残り、分野の広さが最も大きい。ただし、就業率は共通Whyでは他の要因の代わりの可能性が残った（表S7-1でBを通過しない）。また、全国の研究では、週2〜3日以上の収入を伴う仕事は低い幸福感と、特技・経験を伝える活動は高い幸福感と関連した（出典[E3]）。そのため、本施策案は「就業率を上げる」ではなく、「経験を生かす役割を増やす」形で扱う。

  - **所得 → 本施策案の対象外**：所得は産業振興・雇用を通じて間接にしか動かず、70代以上の所得の多くは年金で、市の施策で動かしにくい。おでかけパスの運賃軽減で、外出にかかる費用の負担を和らげる形で間接に配慮する。

  - **家族・同居 → 施策を届ける相手の目印**：配偶者との死別・離別やひとり暮らしは施策で変えられない。一方で、外出が減りやすい人を見つける目印になるため、「届ける」の対象の決め方に使う。

- **学び・文化の場（7点）**：固有Whyで文化・芸術に残ったが、共通Whyでは残らず、和歌山市の値の不利さも小さい。単独の重点にはせず、「行き先と役割」の場（公民館・図書館など）として組み込む。

- **地域の居場所・交流（6点）**：固有Whyで文化・芸術に残ったが、共通Whyでは残らず、和歌山市の値の不利さも小さい。単独の重点にはせず、「行き先と役割」の場（公民館・図書館など）として組み込む。

### 6.3 推奨

- **推奨：H1・H2・H3・H5・H6を組み合わせる。** 足（H1・H2）だけでは出かける目的がなく、行き先と役割（H5）だけでは来られない人が残る。道（H3）は、足と行き先をつなぐ区間を低い費用で改善する。届ける（H6）は、施策を必要な人に結びつける。
- **H4（歩道・公園の新規整備）は、本施策案の中心にしない。** 効果が出るまで年数がかかり、対象を絞れないため。ただし、PoCで外出が増えた経路・地区を、市の道路・公園の整備計画で優先する根拠に使う。
- 組み合わせる理由は、全国の事例でも、移動の「行き先」を協賛店・通いの場にした例（富山市・入間市）や、会場を徒歩圏に増やした例（武豊町）に根拠があるためである［E8・E10］。

## 7. 推奨施策：1つの施策コンセプト

### 7.1 コンセプト

**元気70 おでかけプロジェクト（仮称）：「出かける理由」と「出かける手段」を、男性・70代以上に届くかたちでセットにする**

和歌山市の男性・70代以上は、生活満足が全体的に低く（ステップ4B）、その共通の背景として「出かけにくさ」が最も有力な仮説である（4章）。本施策案は、出かけにくさが、手段・道・行き先・目的・誘いが同時に欠けていることから来るという仮説を立てた（5章）。そのため、本施策案は、個別の施策を別々に行うのではなく、1人の男性・70代以上が「声をかけられる → 安く移動できる → 休みながら歩ける → 行き先に役割がある」という一続きの体験として設計する。

### 7.3 対象と始め方

- **対象者**：和歌山市の男性・70代以上（約3.5万人）。特に、免許を返納した人・返納を考えている人、配偶者と死別・離別した人、ひとりで暮らす人。
- **対象地区の選び方**：市の公共交通不便地域（駅1km・バス停500mの外）のうち、70代以上の男性が多く、歩いて行ける範囲に公園・公民館などの行き先がある地区を選ぶ。

## 8. PoC：効果検証の設計

### 8.1 確かめること

PoCは、ロジックモデルの4段（施策 → 中間指標 → 生活満足 → 幸福度）のそれぞれで、変化があったか、どこで止まったかを確かめる。どの段で止まったかが分かれば、施策の改善点（届いていない・使われていない・満足に結びつかないなど）が分かる。

### 8.2 最初に確かめること：本人の確認でしくみを確かめる

本施策案のWhyは、データから絞った最も有力な仮説で、原因とまでは言えない。そのため、PoCの最初（導入前の調査）で、対象地区の男性・70代以上本人に、次のしくみが実際にあるかを確かめる。

```
外出・移動の環境が悪い（バス停が遠い・歩きにくい・休める場所や行き先がない）
 → 外出が減る（外出の頻度・行き先）
 → 人との接触・役割・文化活動が減る
 → 多くの分野の満足が下がる
 → 幸福度が下がる
```

- **確かめ方**：導入前の調査で、外出・移動の環境（バス停までの距離、運転の有無、歩きやすさ）、外出の頻度、人との接触・役割・文化活動、24分野の満足、幸福度を同じ人に聞き、各段のつながりを見る。
- **しくみが確かめられた場合**：本施策案の4つの柱を、予定どおり段階的に導入する。
- **しくみが確かめられなかった場合**（例：外出は多いのに満足が低い）：外出・移動の環境以外の仮説（3章 ステップ9の仕事・役割、家族・同居など）を重点に置き直し、柱の組み合わせを見直してから導入する。

### 8.3 デザイン

- **段階導入（ステップウェッジ）**：対象の候補地区を、導入時期が早い地区と遅い地区に分ける（可能なら抽選で決める）。まだ始めていない地区を比べる相手にし、差の差で変化を比べる。最終的にはすべての候補地区に導入する。
- **案内文のランダム化**：声かけ（柱①）の案内文を2〜3種類に分けて送り、申込み・利用の割合を比べる。低い費用で、届け方の効果を確かめられる［E7］。
- **用量反応**：おでかけパス・デマンド交通の利用記録（ICカード・運行記録）で、よく使う人ほど中間指標・満足が変わるかを見る。

### 8.4 指標とデータ

| 段階 | 指標 | データ | 時期 |
|---|---|---|---|
| 施策 | パス交付数・利用回数、デマンド交通の乗車数、ベンチ設置数、役割の場の担い手数 | 運行記録・ICカード・事業記録 | 毎月 |
| 中間指標（Why） | 外出が週1回未満の割合、家族以外と会う頻度（週1回以上の割合）、歩数、役割を持つ人の割合 | PoC用の調査（導入前・1年後・2年後）、歩数計またはスマートフォン | 導入前と毎年 |
| 生活満足 | 24分野の満足（デジタル庁の地域幸福度と同じ設問） | PoC用の調査 | 導入前と毎年 |
| 幸福度 | 幸福度（0〜10点、同じ設問） | PoC用の調査、介護予防・日常生活圏域ニーズ調査（3年ごと） | 導入前と毎年 |
| 長期の結果 | 要介護認定、介護給付費、医療費 | 介護保険・国保のデータ（本人の同意の範囲で） | 3年以上 |

- 外出頻度は、「屋外に出れば外出」と定義を示して尋ねる。定義を示さないと、閉じこもりの割合が11.7%と2.8%のように大きく変わる［E6］。
- 設問は、デジタル庁の地域幸福度と、介護予防・日常生活圏域ニーズ調査と同じにそろえ、全国や他の市と比べられるようにする。
- 規模：デジタル庁の調査では、和歌山市の男性・70代以上の回答者は年度ごとに数人〜数十人しかない。PoC用の調査は、導入地区・比較地区それぞれで数百人規模を目安にする。

### 8.5 判断の基準

| 結果 | 考えられること | 次の判断 |
|---|---|---|
| 中間指標が動かない | 施策が届いていない・使われていない | 届け方（柱①）、運行の地区・時間帯、行き先の中身を見直す |
| 中間指標は動くが、生活満足が動かない | 出かけにくさは満足の主な原因ではない可能性 | 3章の他のWhy（ステップ8の固有Whyなど）に重点を移す |
| 生活満足は動くが、幸福度が動かない | 生活満足と幸福度の連動が小さい可能性 | 期間を延ばして確かめる。幸福度に近い別の指標（孤独感・うつ）も見る |
| 4段すべてが動く | 施策仮説が支持される | 地区を広げる。費用と効果を整理し、市の計画（総合計画・交通計画・高齢者福祉計画）の指標に入れる |

## 9. 本施策案で言えること・言えないこと

**言えること**

- 和歌山市の男性・70代以上は、24分野の生活満足が全体として同じ類型の平均より明らかに低い。全体の満足は、同じ地域の中でも幸福度と連動する（ステップ4B・5）。
- 6つのWhy仮説のうち、外出・移動の環境は、データの根拠・和歌山市での課題の大きさ・満足への波及・市の介入可能性のすべてで最も評価が高い。
- 推奨施策の各柱は、国内外の研究・事例に、外出・移動支援や役割づくりと健康・うつ・孤独感との関連を示す根拠がある。

**言えないこと**

- **本施策を行えば幸福度が上がるとは言えない。** 本書の分析は市町村どうしの比較で見た関係で、因果関係は示せていない。外部の根拠の多くも相関や自己申告で、因果を推定した研究は一部（英国の無料バスパス、武豊町のサロンなど）に限られる。
- 和歌山市の男性・70代以上の幸福度が同じ類型の平均より有意に低いとは言えない。男性・70代以上は、幸福度の推定値が最も低く、生活満足が広く低いことから、重点的に検証するWhoとして選んだ。
- 外出・移動の環境が男性・70代以上の満足を下げている原因だとは言えない。本書が示したのは、データから絞った最も有力な仮説である。
- 施策の費用は、他都市の例と市の既存事業からの目安で、和歌山市での見積もりではない。
- 本人が何に不満を持つかは、既存データでは確かめていない。本施策案は、本人の声をPoCの調査で集め、仮説の確認と施策の見直しに使う。
